Each row’s source_id matches a line in sources.csv, which lists the original URL, licence and retrieval date. Coded values (suppressed, not reported, not applicable) are empty with a code column — never 0. See How it works.

Per-school JSON files are at /data/schools/<BSID>.json, and the full pipeline report is at /data/report.md.
