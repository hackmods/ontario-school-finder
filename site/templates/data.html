Licence and attribution

The CSV downloads come from data published under the Open Government Licence – Ontario (including EQAO’s open data, used under licence) and the Statistics Canada Open Licence. If you reuse these files, please keep the source ids and include the attribution text in the box.

The per-school and per-board JSON files also carry two things without an open licence: official attendance boundaries from seven boards’ public map layers (no licence stated; shown while we ask each board for permission) and board spending from the Ministry’s financial statements (published without a licence). The attribution doesn’t cover those; the licence of every source is on How it works. Information we summarise from boards’ own web pages is linked, not copied.

Each row’s source_id matches a line in sources.csv, which lists the original URL, licence and retrieval date. Coded values (suppressed, not reported, not applicable) are empty with a code column — never 0. See How it works.

Per-school JSON files are at /data/schools/<BSID>.json, and the full pipeline report is at /data/report.md.
